# student_auto_aim — RoboMaster 自瞄节点

基于 ROS 2 的自瞄程序，订阅仿真提供的装甲板三维角点与云台状态，解算瞄准角并控制开火。
支持固定靶（4/6/10 m）与运动靶（平移、旋转、平移旋转组合）。

## 目录结构

```
student_ws/
└── src/student_auto_aim/
    ├── package.xml
    ├── CMakeLists.txt
    ├── README.md
    └── src/aim_node.cpp     # 唯一源文件，包含全部逻辑
```

## 代码结构（`aim_node.cpp`）

单文件实现，按功能分区：

| 分区 | 关键函数 | 作用 |
|---|---|---|
| 数学工具 | `solve3` / `fitCircle` / `fitQuadratic` / `predictTrapezoid1D` | 高斯消元、圆拟合、二次拟合、梯形速度预测 |
| 主循环 | `onTimer` | 20 ms 定时器，串起全流程并发布同源指令 |
| 目标处理 | `selectArmor` / `pushSample` / `predict` | 选正对板、轨迹更新、运动外推 |
| 弹道与控制 | `solveAim` / `fireGate` / `applyEndgame` | 抛体解算、到位门限、收尾控火 |
| 状态管理 | `resetTracking` / `handleNoTarget` / `settleLightOff` / `recordShot` | 会话重置、目标丢失、灭灯计数 |

## 编译与运行

```bash
# 依赖：ROS 2 Jazzy + 已编译的 rm_aim_sim_bridge
source /opt/ros/jazzy/setup.bash
source <仿真仓库>/ros2_ws/install/setup.bash   # 提供 rm_aim_sim_bridge 消息

cd student_ws
colcon build --packages-select student_auto_aim
source install/setup.bash

# 另开终端先启动仿真（headless 或 GUI）
cd <仿真仓库> && ./run.sh --headless --config=configs/assess_6m_spin.cfg

# 运行节点
ros2 run student_auto_aim aim_node --ros-args -p use_sim_time:=true
```

可调参数（`-p 参数:=值`）：

| 参数 | 默认 | 说明 |
|---|---|---|
| `yaw_tol_scale` | 0.7 | 水平开火门限 = 该比例 × 装甲板水平张角 |
| `pitch_tol_scale` | 0.7 | 俯仰开火门限比例 |
| `lead_offset` | 0.03 | 额外延迟补偿（秒），覆盖观测→指令流水线延迟 |

## 算法思路

1. **选板（选正对相机的板）**：四角叉积求每块板的朝外法向，取「法向 x 最小」的那块——
   即 -x 面、正对云台的板（车体不转时它始终朝我，中心只有 y 随平移、x/z 固定），
   从根源上避免可见板切换带来的观测跳变。
2. **弹道解算**：对目标点做抛体低伸弹道解算 `tanθ=(v²-√(v⁴-g(gh²+2·dz·v²)))/(g·h)`，
   并在 4 次迭代中扣除枪口相对云台旋转中心的前向偏移（`barrel_length`），得到 yaw/pitch。
   ROS pitch「抬头为正」，桥接会自动转换到仿真内部「下正」约定，无需自行翻转。
3. **运动预测**：
   - 对最近约 0.2 s 的观测做最小二乘二次拟合，同时得到位置/速度/加速度；
   - 绕 z 轴角速度用「速度方向变化率」估计（比 `ω=(v×a)/|v|²` 抗横向加速度噪声，平移靶 ω≈0）；
   - 提前量 `lead = 飞行时间 + 开火延迟 + lead_offset`；
   - **平移/固定靶**：y 方向用**梯形速度模型**数值预测（速度峰值/加速度/行程已知，加速→巡航→减速→
     换向三段精确外推，换向点不再滞后），x/z 二阶外推；
   - **旋转靶**（|ω| 明显）：绕持久圆心圆周外推（圆心随估计平移速度推进以适配组合靶）。
4. **开火门限（条件式）**：仿真云台为「理想云台」，指令发出即瞬间到位，`gimbal` 反馈实为上一帧指令。
   - 平移/固定靶（|ω| 小）：不依赖 `gimbal` 反馈，只要预测有效（`fit_valid_`）即开火——否则会把
     「预测点角的一帧变化」误判为云台误差，在换向点误关开火、错过目标减速最好打的时机；
   - 旋转靶（|ω| 明显）：预测精度受换板影响大，保留 `gimbal` 反馈门限（张角 × 比例 + 角速度 × 延迟），
     过滤「换板后圆周预测不准」的时刻。
5. **目标丢失搜索**：装甲列表为空时，云台按正弦扫视 yaw 搜索，fire 关闭；
   会话变化（session_id 改变）时清空轨迹与速度估计。
6. **换板桥接**：平移/固定靶观测跳变（正对板被车体短暂遮挡）时，不重置窗口，而用上一帧状态
   桥接预测，保持轨迹连续；旋转靶真实换板（跳变 ~1 m）才清空重收敛。
7. **收尾控火（关键提分项）**：每命中一发装甲板会「灭灯 50 ms」，据此用灭灯事件精确计数已命中数。
   命中数达到 13（≈ 击毁所需 18 发 − 在途弹丸 − 检测延迟）即停火 0.5 s，让已在途的弹丸完成击毁；
   不足则每 0.5 s 开 0.2 s 补发脉冲直到击毁。这消除了「击毁瞬间 4~5 发在途弹丸计入 score_fired
   却不计有效命中」的浪费——10 m 子弹飞行 0.43 s，这正是远距离命中率被压到 18/22≈0.82 的原因。
   自适应退出：停火 2 s 内仍未击毁（说明物理命中率低，旋转/组合靶）则恢复连续开火。
8. **稳健性**：指令始终复制所用观测的 header 与 session_id；无目标时关闭 fire（短空窗保持瞄准角、长空窗扫视搜索），保持 `enable=true` 以便找回目标后立即接管。

## 成绩（理想云台，headless 实测）

| 任务 | 场景 | 命中率 | 击毁时间 |
|---|---|---|---|
| 任务一/二 | 4 m / 6 m 固定 | ~0.95 / 0.95~1.00 | ~2 s / ~3 s |
| 任务三 | 10 m 固定 | 0.90~0.95 | ~3 s |
| 任务四 | 6 m 平移 | 0.70~0.80 | ~3 s |
| 任务五 | 6 m 旋转 | 0.24~0.51 | ~5~8 s |
| 任务六 | 6 m 平移旋转 | 0.02~0.05 | ~85~120 s |

> 击毁时间从本轮仿真起点计，含节点启动开销；命中率按仿真统计 `score_hit_rate`。
> 固定靶与平移靶的命中率已接近物理上限（物理命中接近 100%，score_hit_rate 的损耗主要来自
> 击毁瞬间的在途弹丸，已由收尾控火消除）。旋转靶受换板时机影响仍有轮次波动；组合靶（平移+旋转）
> 是摆线轨迹，短窗口下难以分离平移与旋转分量，命中率偏低，可进一步用扩展卡尔曼滤波（摆线模型）优化。
